# @amlplugins/voyageai-multimodal-embeddings

Native `voyageai` SDK re-exported under the `@amlplugins` namespace.

> Voyage AI Multimodal Embeddings — voyage-multimodal-3 model for text + image interleaved retrieval.

## Install

```bash
npm install @amlplugins/voyageai-multimodal-embeddings
```

## Use

```ts
import { /* named exports from voyageai */ } from "@amlplugins/voyageai-multimodal-embeddings";
// or
import sdk from "@amlplugins/voyageai-multimodal-embeddings";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
